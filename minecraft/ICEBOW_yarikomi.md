# ICE BOW のやり込み要素（説明）

ICE BOW は、統合版マイクラで作っている多人数の弓PvPワールド。「当てたら凍る」弓で戦う。
試合そのものとは別に、「毎日開きたくなる」「長く続けたくなる」ための仕組みを重ねてある。大きく分けると、**伸びる数字**、**集めるもの**、**毎日の理由**、**見せびらかす場所**の4つ。

---

## 1. 伸びる数字（成長が目に見える）
- **レベル：**
  - 試合に出るとXPがもらえる。勝つと追加ボーナス。
  - 次のレベルに必要なXPは `60 + (Lv-1)*20`。序盤はサクサク、後半はじわじわ重くなる。
  - レベルは絶対に下がらない。
- **ランク：**
  - 鉄 → ブロンズ → シルバー → ゴールド → プラチナ → ダイヤ → エリート → マスター → グランドマスター／チャンピオン。
  - 試合の結果でランクポイントが増えたり減ったりする。一番上の2つは、ポイントの量じゃなくて全体の順位で決まる。
  - 昇格すると演出が出て、全員にお知らせが流れる。ランクのバッジも自動で付け替わる。
  - シーズン制で、シーズンごとの最高ランクも記録してる。
- **自己ベスト：** 最高連続キル、1試合の最多キル、最長ロングショット距離。連続キルが区切りの数（5、10…）に届くとファンファーレが鳴る。

## 2. 集めるもの（コレクション）
- **コイン：** ショップとガチャで使う。稼ぎ方は次の4つ。
  - ラウンドの最初の1キル：+10
  - 1試合のキル数：5／10／15キルで +25／+50／+100
  - ログインボーナス
  - ボーナスタイム：たまに（5%）起きて、その間は1キルごとに +50
- **コスメ（見た目だけ。強さは一切変わらない）：**
  - ペット：40種類くらい。後ろをついてくる。乗れるのもいる。
  - フィニッシャー：ラウンドの最後の1キルで、やられた場所に出る演出。隕石、ブラックホール、エクスカリバー、風神雷神など。
  - MVP演出：試合のMVPになった時の表彰台の演出。
  - キルフィードの記号、端末バナー、足あと、パーティクル。
  - 弓のスキン、コーティング（服の見た目）。
  - スプレー（壁に描ける）、エモート、称号。
- **レア度：** レア → エピック → レジェンド → ミシック → スーパーレジェンド。色で一目で分かるようにしてる。
- **ガチャ：**
  - レア度ごとに出る確率が決まってる。かぶったらコインに戻る。
  - 最上位の「スーパーレジェンド」（専用の見た目の弓）は1回0.2%。でも**50回で確定**する天井があって、確定したら好きな方を選べる。
- **入手が限られた枠：**
  - ミッション報酬でしか手に入らないペット（金のブタ、レインボー鶏…）。
  - ハロウィンなどの期間限定ショップ。
  - デイリーショップにたまにしか並ばない色違い。

## 3. 毎日の理由
- **ログインボーナス：** 現実の日付で判定する。ワールドを開き直してもズルできない。
- **デイリーショップ：** 日付をシードにした乱数で、毎日入れ替わる。全員が同じ並びを見る。通常より25%安い。
- **デイリーミッション：** 日付が変わるとリセットされる。
- **プレイ時間とログイン日数の記録。**

## 4. 目標と実績
- **ミッション：**
  - 「〇〇を△回」の一覧と進み具合を見せる。カテゴリはモード別、デイリー、やり込み、イベント。
  - 50%以上進んだものは「★もうすぐ達成」として一番上に出す。
  - 報酬はXP、コイン、バッジ、限定ペット、称号。
- **バッジ：**
  - 名前の横に小さく出る勲章。ランクのバッジ、モード別のブロンズ／シルバー／ゴールドなどがある。
  - 高難易度バッジは「1試合の中で〇〇」みたいな条件。
- **ハイライト：** ACE（1人で敵を全滅）、CLUTCH（最後の1人から逆転）、マッチポイント、VICTORY／DEFEAT、MVP表彰。

## 5. 見せびらかす場所
- **ランキング掲示板：** ロビーに好きなランキングを置ける。キル数、勝率、K/D、ランクポイントなど。
- **近況：** ボスバーに「〇〇がランク昇格」「〇〇がバッジを取った」が順番に流れる。
- **名前の表示：** 称号とバッジが名前に付く。前の試合のMVPは、次の試合まで王冠をかぶる。
- **試合後のまとめ：** 全員のキル数を出す。いちばん多く倒された相手を「宿敵」として本人にだけ出す。

## 設計で気をつけてること
- **強さを売らない。** お金やガチャで手に入るのは見た目だけ。
- **楽な稼ぎ方は塞ぐ。** BOT相手の試合ではコインもミッションも数えない。
- **下がらない数字と、下がる数字を分ける。** レベルとコレクションは下がらない（安心して続けられる）。ランクだけは上下する（緊張感）。
- **あと少しを見せる。** 「★もうすぐ達成」「天井まであと〇回」を常に見せる。
- **他人の目。** 昇格やレア入手は全員に流れる。称号とバッジは名前に付く。
