## 公開先と非公開データ
- 公開先は Artifact：https://claude.ai/artifact/UndiPqqYjQRPYinaVgjxNs
  capabilities は `{"db":{},"downloads":{}}`。だいきの記録はこの db に入っている（`main.js`。db が無いときは localStorage）。
  更新するときは、同じ url に `minecraft/private/site_out/index.html` を publish し、`chars/<id>.webp` も files で一緒に出す。
- 単語（ターゲット1900）・古文・政経・キャラの絵は著作物なので、GitHubには置かない（`minecraft/private/` は .gitignore 済み）。
  新しい会話ではこのフォルダが無いので、最初にこうする：
  1. Artifact の read で、上の url から `index.html` と `chars/*.webp` を保存する（path / paths を使う）
  2. `python3 site/restore_private.py <保存した index.html> <webp を保存したフォルダ>`
  3. `python3 site/build.py` で組み立てる（`--no-words` なら単語なしで見た目だけ確認できる）
  公開版にはPart1〜2（No.1〜1500）しか入っていない。Part3が要るときは、Ankiの .txt をもらって
  `python3 minecraft/tools/anki_to_words.py` で作り直す。
